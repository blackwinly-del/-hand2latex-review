Hand2LaTeX 智能工作台 —— 安装与使用说明
=========================================

这个包做什么
------------
把手写笔记的照片变成可以编辑的 LaTeX，再排成中文 PDF。
左边看原图，中间改代码，右边看效果；识别出来的每一处风险都会标黄，方便你逐处核对修改。


一、运行前需要准备什么（重要）
------------------------------
1. Windows 10 / 11，64 位。
2. Python 3.10、3.11 或 3.12（必须是这三个版本之一，3.13 不行）。
   检查：在命令行里运行  python --version
   没有的话去 https://www.python.org/downloads/windows/ 下载，安装时勾选 "Add python.exe to PATH"。
3. 一个能用的大模型 API 密钥（整页识别是云端做的）。
4. 首次启动需要联网：会自动建虚拟环境并安装 Python 依赖（几百 MB，视网速几分钟到十几分钟）。

已经随包带上、不用你操心的：
  - PDF 编译器 Tectonic（tools\tectonic\tectonic.exe）
  - 网页前端 Vue（workbench\static\vendor\vue\vue.global.js），所以不需要装 Node.js

没有随包带的：
  - 本地公式模型 models\（约 3 GB）。只有"画板"（单公式手写识别）用得到，
    整页识别走云端，不装也能正常用。需要时见下面第五条。


二、绿色包（zip）怎么装
-----------------------
1. 把 zip 解压到一个"可写"的地方，例如  D:\  或  C:\Users\你的用户名\Documents
   解压出来是一个名叫  Hand2LaTeX-<版本>-win64  的文件夹，所有文件都在这个文件夹里，不会撒到外面。
   不要解压到 C:\Program Files 下面：程序要在自己的目录里写任务产物，那里默认没有写权限。
2. 打开那个文件夹，双击  启动工作台.bat
   第一次运行会自动准备虚拟环境和依赖，屏幕上每一步都会写清楚做了什么、成功还是失败。
3. 浏览器会自动打开 http://127.0.0.1:8000/ （没自动打开就自己复制这个地址）。
4. 关闭：双击  关闭工作台.bat ，或者直接关掉那个命令行窗口。


三、安装器（setup.exe）怎么装
-----------------------------
1. 双击  Hand2LaTeX-<版本>-win64-setup.exe
2. 默认装到  C:\Users\你的用户名\AppData\Local\Programs\Hand2LaTeX （不需要管理员权限）。
3. 装完可以从开始菜单或桌面快捷方式启动，也可以在安装结束页勾选"立即启动"。
4. 卸载：Windows 设置 → 应用 → Hand2LaTeX。
   卸载会自动删掉虚拟环境（.venv，体积很大）；你自己的历史任务在 artifacts\jobs 下，
   卸载向导会单独问你要不要删——想留就选"否"，或提前把 artifacts\jobs 复制到别处。


四、填 API 密钥（必须做，否则识别用不了）
-----------------------------------------
1. 打开程序目录下的  .env  （第一次启动时会自动从 .env.example 复制出来；没有就自己复制一份）。
2. 用记事本编辑，把这一行填上：
       OPENAI_API_KEY=你的密钥
   如果用国内服务，通常还要填这两行（以服务商给的为准）：
       OPENAI_BASE_URL=https://api.deepseek.com/v1
       OPENAI_MODEL=deepseek-flash
3. 保存后重新启动工作台。
4. 这个文件只留在你自己电脑上，不会被打包、不会被上传，也不要发给别人。


五、启动后先做两件事
--------------------
1. 看页面最上面的"系统状态"一排圆点：
     绿色 = 能用，黄色 = 要注意，红色 = 不能用。
   点"查看详情"能看到具体依据：用的哪个模型、密钥有没有填（只显示长度，不显示内容）、
   Tectonic 在哪、中文字体配置、最多同时识别几页、任务目录占了多少空间。
   这里只列能当场核对的事实。系统不给"识别可信度分数"——那种分数没法验证，只会误导。
2. 想跑本地公式模型（画板）的话：装好依赖后首次运行会自动下载模型到 models\ 目录；
   已经有模型的话，在 .env 里设置 RECOGNIZER_MODEL_DIR 指向那个目录即可。


六、日常怎么用
--------------
1. 第一步：上传手写笔记照片（png / jpg / webp，可以一次选多张，按你选的顺序合成一份 PDF）。
   识别时页面上会显示每一页的实时状态（等待中 / 识别中 / 已完成 / 失败）和已用时间。
   多页是并行识别的，页数越多提速越明显；想调并发数，在 .env 或环境变量里设
   WORKBENCH_PAGE_CONCURRENCY（默认 3，最大 10）。
2. 第二步：中间栏改代码。
     - 黄色底纹的行 = 系统认为需要你复核的地方，鼠标停上去会说明为什么可疑、该怎么改。
     - 每页缩略图下面有"识别过程记录"：这一页识别用了多久、输出多少 token、
       是不是被截断过重试、识别出几段文字几个公式。这些是真实记录，不是打分。
     - Ctrl+S 重新排版；代码没变时会直接复用上次结果，不再白等一遍编译。
     - F2 跳到下一处待复核，界面上会显示"正在看第几处 / 共几处"。
     - 改动会自动存到这台电脑的浏览器里，误关页面还能点"恢复我的修改"找回来。
     - 右边"历史版本"标签页列出每次保存的版本，可以随时退回；当前版本也在列表里，
       所以退错了还能再退回来。
3. 第三步：右边看 PDF，不满意就回到中间栏继续改。
   PDF、当前 .tex、识别原稿都可以下载。某一页识别失败时，可以只重试那一页。


七、出问题先看这里
------------------
- 网页白屏 / 报 "Vue is not defined"：前端资源缺失，看"系统状态"里的"网页前端资源"那一条，
  按提示运行 npm install，或重新解压完整的安装包。
- 上传后一直转圈然后报超时：多半是网络连不上模型接口。检查 .env 里的 OPENAI_BASE_URL，
  以及这台机器能不能访问该地址。
- 报 "OPENAI_API_KEY 未配置"：第四条没做。
- 能识别但排不出 PDF：状态里"PDF 编译器"是红色，说明 tools\tectonic\tectonic.exe 不见了，
  重新解压安装包即可。
- PDF 里中文变成方框或空白：状态里"中文字体配置"会提示；Windows 上默认 fontset=windows，
  一般不需要改。
- 某个数学符号在 PDF 里缺字：那一行会被标黄并写明原因，按提示把符号换成 LaTeX 写法
  （例如 $\in$、$\le$）。
- 端口 8000 被占用：先运行  关闭工作台.bat ，或用
      powershell -ExecutionPolicy Bypass -File scripts\launch.ps1 -Port 8010
  换个端口启动。
- 想只看体检结果、什么都不装：
      powershell -ExecutionPolicy Bypass -File scripts\launch.ps1 -CheckOnly


八、需要知道的两点实话
----------------------
1. 识别结果不是 100% 正确的，尤其是潦草的手写公式。系统的目标不是"保证对"，
   而是"让你很容易看出哪里可能不对、很容易改"。请以原图为准逐处核对。
2. 系统不会给"可信度百分比"。页面上所有的提示都来自能当场核对的事实
   （编译器日志、模型返回的 token 用量与结束原因、是否发生过重试、识别耗时）。
   凡是没法验证的数字，一律不显示。
