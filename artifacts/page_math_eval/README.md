# page_math_dataset 单公式真值评估（2026-11-26）

本目录是一次**真实运行**的评估证据，用 100 页 `page_math_dataset` 里 370 条互不重复的
单公式真值，测本地识别引擎（UniMERNet）的精确匹配率。**不含裁切图**（约 7 MB），
只保留清单、逐条结果与汇总，保证任何一条都能被独立复核。

## 数据集是什么、不是什么

- 来源：`page_math_dataset.zip`（100 页、1240×1754 px、1663 个公式条目）。
- 笔迹是**真实的**：每条公式的笔画取自 MathWriting 原始样本，只做了等比缩放与旋转排版。
- LaTeX 是**人工标注**的：直接用 MathWriting 的 `normalizedLabel`，不是模型生成的。
- 版式是**脚本生成的**（单列纵向堆叠），所以它**不等于**真实拍摄的整页照片；
  能评单公式识别准确率，不能代表整页拍摄场景。

## 怎么跑的

- 裁切：直接按 `annotations.jsonl` 的 `bbox`（已是 1240×1754 像素坐标）裁切，外加 2% 边距，
  **不缩放**。（对方 `import_page_dataset.py` 之所以乘 0.75，是因为它把页面转成 PDF 再按 930pt
  渲染；这里是原图，所以不乘。）
- 去重：按唯一 `latex` 去重，1663 条 → 370 条；首次出现的那一页/位置为准。
- 引擎：`UniMERNet`，`RECOGNIZER_DEVICE=gpu:0`（RTX 5070 Laptop，paddle 3.4.0）。
- 链路：`recognizer.recognize()` → `reasoner.refine()` → `normalize_latex()`（只 `strip`）完全相等。
- 每条只跑一次。

## 结果

| 口径 | 结果 |
| --- | --- |
| 全量 370 条 strict | **36/370 = 9.7%** |
| 全量 370 条 loose | 48/370 = 13.0% |
| 子集 353 条（跳过 `latex` 长度 ≤ 7）strict | 33/353 = 9.3% |

`strict` 是 `strip` 后字符串完全相等（与项目原有 12 样本评估同一口径）。
`loose` 额外归并了 `\vert`/`|`、`\left`/`\right`、空白、`\dfrac`/`\frac` 等写法差异，
**只作诊断，不是主指标**——`|0|<|1|` 与 `\vert0\vert<\vert1\vert` 语义相同、字符串不同，
strict 会判错。

按真值长度分档：

| 长度 | strict |
| --- | --- |
| 0–7 | 3/17 (17.6%) |
| 8–15 | 10/58 (17.2%) |
| 16–30 | 20/151 (13.2%) |
| 31+ | 3/144 (2.1%) |

0 条出错；单条耗时中位 0.72 s，370 条合计 381 s——**这 381 s 已经包含首次调用的模型加载
（60.7 s，记在第一条记录的 `seconds` 里）**，扣掉之后的稳态速度约 0.86 s/条。

## 两个对照

1. **装置可信**：同一套代码、同一模型跑项目原有的 12 样本真值
   （`data/handwritten_ground_truth.json`），得到 **8/12 = 66.7%**，复现了历史数字。
   见 `control_12.json`。
2. **差距不是分辨率**：12 样本高 55–100 px（中位 68），本批裁切图高 52–75 px（中位 62），
   同一量级；把 40 条抽样放大 3 倍，strict 只从 12.5% 变到 15.0%，在噪声内。
   见 `summary.json` 的 `resolution_check`。

结论：8/12 那 67% 是在 12 张同族求导题上得到的，不能外推；在 370 条多样公式上，
同一模型同一口径只有约 10%。

## 边界（不要拿来当别的结论用）

- 只评**单公式识别**，不评云端整页识别链路、不评版式还原与跨页连贯。
- 版式是合成的，不是真实拍摄；光照、倾斜、纸张等真实退化都没有。
- 每条只跑一次，重复运行的稳定性未验证。
- 这里是本地 B 侧引擎；云端整页那条链路的效果不在此目录范围内。

## 文件

- `manifest.json` — 370 条样本清单（`sample_id`、`ground_truth`、`latex_len`、`image_path`）。
  `image_path` 指向 `crops/`，该目录**未入库**，可按上面"裁切"一节的规则从原数据集重建。
- `records.jsonl` — 逐条结果：真值、识别原文、候选数、strict/loose 对错、耗时、异常。
- `summary.json` — 汇总（数据集、方法、分档、对照实验、分辨率实验）。
- `control_12.json` — 12 样本对照的逐条结果。
