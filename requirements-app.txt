# 为什么不直接用 requirements.txt：那里面有 torch（几个 GB），而 torch 只被
# reasoning/risk_mlp.py、reasoning/train_risk.py 和 recognizer.py 用到；Pillow 与
# numpy 只被 demo/app.py 和 recognizer.py 用到。这三处都不在"上传 → 整页识别 →
# 编译 → 复核"这条链路上，而且在 recognizer.py 里都是函数内延迟导入，所以不装也能跑。
# 版本号与 requirements.txt 保持一致，避免两条链路上的行为分叉。

# 元包，会拖进 pymupdf-layout（onnxruntime 54 MB + numpy 55 MB + networkx 18 MB）
# 和 pymupdf4llm，随包运行时因此从约 100 MB 涨到 324 MB。代码里只用到
# pymupdf.open() / page_count / get_text() / get_images() / get_drawings()
